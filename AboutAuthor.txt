In March 2026, I was building an AI orchestration system designed to make different AI systems — 
Claude, ChatGPT, Gemini, Copilot, and virtually any others — work together on the same project.

My AI orchestration system aims to be consistently more clever, more capable, and more productive than any of these AIs can be on their own.

A central piece of this orchestration system is shared storage, to which all non-temporary, non-garbage files of a project under development — 
and, more generally, all relevant files worth being accounted for by an AI — 
are automatically mirrored when they are created, closed after an update with debounce, renamed, moved, metadata-updated, or deleted.

This is how SelectiveMirror, a standalone Windows service, was born. I am pleased to make it a free and open-source public utility.
A chosen transport layer for the mirroring is an external utility rclone which supports over 70 file systems and cloud storage backends.
